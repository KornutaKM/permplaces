# PermPlaces

Telegram-ассистент для поиска кафе, ресторанов, баров и других мест в Перми.

## Статус

Версия 0.2 подключает реальный поиск заведений рядом с пользователем через OpenStreetMap/Overpass.

Рабочий вертикальный сценарий:

```text
/start
  ↓
📍 Рядом со мной
  ↓
категория
  ↓
OpenStreetMap / Overpass
  ↓
5 ближайших мест
  ↓
карточка → следующая/предыдущая → маршрут
```

## Уже работает

- Telegram UI на aiogram 3;
- получение геолокации;
- категории заведений;
- live-поиск OSM вокруг координат пользователя;
- радиус 500 м / 1 км / 3 км / 5 км;
- сортировка по фактическому расстоянию;
- карточки с адресом, opening_hours и cuisine, когда эти поля есть в OSM;
- переход между результатами;
- отправка точки заведения через Telegram Location;
- ссылка на исходный OSM-объект;
- обязательная атрибуция © OpenStreetMap contributors / ODbL;
- текстовый поиск по поддерживаемым категориям;
- часть готовых сценариев;
- Ruff + pytest;
- Docker build/smoke CI.

## Принцип данных

PermPlaces не придумывает отсутствующие факты.

Если OpenStreetMap не содержит рейтинг, средний чек, адрес, часы работы или меню, бот не подставляет их самостоятельно.

Каждая OSM-карточка сохраняет:

- provider: `osm`;
- тип и ID OSM-объекта;
- исходную ссылку;
- координаты;
- поля, реально присутствующие в тегах OSM.

## Ограничения текущего этапа

Точный поиск по административным границам районов Перми пока не подключён. Кнопка выбора района остаётся в UX, но live-поиск сейчас требует геолокацию пользователя.

Рейтинг, отзывы, средний чек и полноценное меню OpenStreetMap обычно не предоставляет. Для этих данных понадобится второй provider.

## Локальный запуск

Требуется Python 3.12+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -e ".[dev]"
```

Создайте `.env`:

```env
BOT_TOKEN=your_telegram_bot_token
OVERPASS_URL=https://overpass-api.de/api/interpreter
OVERPASS_TIMEOUT_SECONDS=20
```

Запуск:

```bash
python -m app.main
```

Проверки:

```bash
ruff check .
pytest
docker build -t permplaces .
```

## Архитектура

```text
Telegram
   ↓
aiogram handlers
   ↓
SearchService
   ↓
PlacesProvider protocol
   ↓
OverpassProvider
   ↓
OpenStreetMap
```

Provider abstraction позволяет позже добавить 2GIS или другой источник без переписывания Telegram UX.
